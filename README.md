# Ashby & Vale redesign preview

Open `index.html` to review the site. The redesign keeps the supplied static HTML, CSS, JavaScript, fonts, images, and case-review flow. It uses a warm paper/ink/brick palette, an editorial hero, a separate situation picker, quieter case and process layouts, still testimonials, and a less card-heavy team and FAQ presentation. The office status is plain text, the mock-number band has been replaced with an editorial note, and decorative icons have been removed in favor of clear labels and restrained typography.

## Before publishing

The source ZIP labels its case outcomes and testimonials as mock content, its portraits as AI-generated placeholders, and the privacy policy as draft copy. The supplied phone number uses a 555 exchange. Verify all firm, attorney, result, fee, timing, contact, and policy claims, and replace the placeholder imagery before launch.

The case-review form has no configured backend. It opens the visitor's email application with a prepared message. Set `CONFIG.formEndpoint` in `script.js` only after connecting a real secure intake endpoint.

The site has no external icon dependency.
